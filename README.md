# Forushyar-AI
شرحی که ارائه کرده‌اید، مبنای مناسبی برای طراحی یک سامانه یکپارچه فروش، مرکز تماس هوشمند، مدیریت انبار و پشتیبانی مشتریان با هوش مصنوعی است.

نکته مهم این است که این پروژه نباید صرفاً به شکل یک چت‌بات طراحی شود؛ بلکه باید یک سامانه عملیاتی باشد که بتواند مکالمه کند، اطلاعات واقعی را از سیستم دریافت کند و با رعایت کنترل‌های امنیتی، عملیات فروش و پشتیبانی را انجام دهد.

## ۳. چند تصمیم مهم در طراحی

مدیریت موجودی: موجودی هر سه انبار باید به‌صورت مستقل ثبت شود. برای هر فروش، عملیات رزرو موجودی و ثبت سفارش باید کنترل‌شده و اتمیک باشد تا دو مشتری نتوانند هم‌زمان یک کالای موجود را خریداری کنند. ورود Excel و CSV نیز باید ابتدا اعتبارسنجی شود و سپس به‌صورت یک عملیات ثبت‌شده وارد سیستم شود.

پرداخت و صدور فاکتور: هوش مصنوعی فقط درخواست پرداخت را پیگیری می‌کند. تأیید پرداخت باید از طریق پاسخ معتبر درگاه یا تأیید اپراتور انجام شود. پس از آن، سیستم مجاز به نهایی‌کردن سفارش، صدور فاکتور و ثبت گردش انبار خواهد بود.

تلفن هوشمند: پیشنهاد می‌شود UCM6202 از طریق SIP به یک لایه واسط تلفنی متصل شود. این واسط تماس را دریافت می‌کند، صدای مشتری را به موتور هوش مصنوعی می‌رساند و پاسخ صوتی را به تماس برمی‌گرداند. انتقال تماس به کارشناس انسانی نیز باید در همین لایه مدیریت شود.

هوش مصنوعی محلی و ابری: موتور هوش مصنوعی باید قابلیت استفاده از مدل محلی و سرویس ابری را داشته باشد. پاسخ به اطلاعات محصولات، قیمت و موجودی باید از API سامانه دریافت شود، نه از حافظه مدل زبانی.

بخش بیماران: این قسمت باید از نظر دسترسی و نگهداری اطلاعات محرمانه از فروش جدا باشد. پاسخ‌گویی به اطلاعات عمومی و محتوای تأییدشده مجاز است، اما تشخیص پزشکی و تجویز دارو باید خارج از وظایف هوش مصنوعی باقی بماند.
