# Forushyar-AI v0.4.11 — Excel product import

این بسته، ورود گروهی کالا از فایل `.xlsx` را به صفحه `/admin/products` اضافه می‌کند.

## نصب روی Debian

1. فایل ZIP را در Debian در یک پوشه موقت استخراج کنید.
2. از پوشه استخراج‌شده اجرا کنید:

```bash
bash install_v0411.sh "$HOME/forushyar-AI"
```

یا اگر پروژه مسیر دیگری دارد، مسیر واقعی آن را جایگزین کنید.

اسکریپت پیش از تغییر فایل‌ها، نسخه پشتیبان را در مسیر مخفی `.backups/` داخل پروژه قرار می‌دهد. فایل‌های دیتابیس و Volumeهای Docker تغییر نمی‌کنند.

## بررسی و ساخت

```bash
cd ~/forushyar-AI
git diff --check
git status --short

docker compose build api
docker compose up -d --no-deps api
docker compose ps api
docker compose logs --tail=100 api
curl -fsS http://127.0.0.1:8000/health/live
```

در خروجی health انتظار می‌رود نسخه `0.4.11` دیده شود.

## تست در مرورگر

به `/admin/products` بروید، کلید API را وارد کنید و اتصال را برقرار کنید. سپس:

1. «دانلود قالب Excel» را بزنید یا فایل XLSX موجود را انتخاب کنید.
2. «پیش‌نمایش و اعتبارسنجی» را بزنید.
3. کدهای انبار فایل را به انبارهای واقعی فروش‌یار نگاشت کنید.
4. فقط بعد از بررسی صحت قیمت و تعداد، «تأیید و ثبت گروهی» را بزنید.

**هشدار:** پیش‌نمایش هیچ داده‌ای را ثبت نمی‌کند؛ اما تأیید نهایی، کالاها و موجودی‌ها را واقعاً در دیتابیس ثبت می‌کند. کد انبار `10001` فایل نمونه به‌صورت خودکار به انبار خاصی وصل نمی‌شود. همچنین تعدادهای فایل نمونه را فقط وقتی ثبت کنید که مقادیر واقعی شمارش انبار هستند.

## API

- `GET /api/v1/products/import/template`
- `POST /api/v1/products/import/preview` — multipart field: `file`
- `POST /api/v1/products/import/confirm` — JSON body: `{ "rows": [...] }`

هر سه endpoint به هدر `X-API-Key` نیاز دارند.

## محدودیت‌های عمدی این نسخه

- فقط `.xlsx`؛ فایل قدیمی `.xls` پشتیبانی نمی‌شود.
- سقف حجم فایل ۵ مگابایت و سقف ۵۰۰۰ ردیف داده است.
- SKU موجود در سامانه به‌روزرسانی نمی‌شود؛ به‌عنوان خطا گزارش می‌شود.
- فرمول‌های Excel پذیرفته نمی‌شوند؛ سلول‌ها باید مقدار نهایی داشته باشند.
- خالی بودن قیمت یعنی قیمت ثبت نشود؛ قیمت صفر یک قیمت معتبر است.
- برای ثبت موجودی، کد انبار و موجودی اولیه باید هر دو تکمیل باشند. صفر بودن موجودی معتبر است.
