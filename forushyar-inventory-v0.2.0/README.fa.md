# به‌روزرسانی فورش‌یار – نسخه 0.2.0

این بسته عملیات اصلی انبار را به کد فعلی پروژه اضافه می‌کند و هیچ محصول یا موجودی آزمایشی وارد نمی‌کند.

## قابلیت‌های اضافه‌شده

- رسید ورود کالا و حواله خروج کالا
- انتقال اتمیک یک کالا بین دو انبار
- رزرو، آزادسازی و مصرف رزرو
- کنترل موجودی آزاد (`on_hand - reserved`)
- جلوگیری از موجودی منفی و رزرو بیش از موجودی آزاد
- دفتر گردش با دو مقدار مستقل `quantity_delta` و `reserved_delta`
- تاریخچه قابل فیلتر برای گردش‌ها، انتقال‌ها و رزروها
- کلید جلوگیری از ثبت مجدد عملیات (idempotency)
- قفل ردیف دیتابیس برای تغییر مانده و ترتیب قفل ثابت در انتقال‌ها

## نصب روی Debian

1. این فایل را به سرور کپی کنید.
2. در یک پوشه موقت استخراج کنید:

   ```bash
   mkdir -p /tmp/forushyar-v020
   tar -xzf forushyar-inventory-v0.2.0.tar.gz -C /tmp/forushyar-v020
   ```

3. وارد ریشه پروژه فعلی شوید:

   ```bash
   cd ~/forushyar-AI
   ```

4. اسکریپت نصب را اجرا کنید:

   ```bash
   bash /tmp/forushyar-v020/forushyar-inventory-v0.2.0/install_inventory_v0.2.0.sh
   ```

اسکریپت قبل از تغییر کد، از سورس فعلی و PostgreSQL پشتیبان می‌گیرد؛ سپس image جدید API را می‌سازد، Migration را با یک اجرای موقت اعمال می‌کند و بعد API جدید را بالا می‌آورد. PostgreSQL، Redis، Volumeها، Compose و `.env` حذف یا بازنویسی نمی‌شوند.

## خروجی مورد انتظار

- Alembic revision: `0002_stock_ops (head)`
- `/health/ready` باید `{"status":"ready"}` برگرداند.
- در حالت development، مسیرهای جدید در `/openapi.json` دیده می‌شوند.

## محدودیت‌های مشخص این نسخه

- هر درخواست انتقال در این نسخه برای یک SKU است؛ انتقال چندقلمی در توسعه بعدی افزوده می‌شود.
- هویت کارمند در دفتر گردش ثبت نمی‌شود، چون سامانه کاربران و نقش‌ها هنوز ساخته نشده است. در این نسخه نوع عملیات، مقدار، دلیل، ارجاع و زمان ثبت می‌شود.
- اتصال به منبع واقعی Excel/CSV هنوز انجام نشده است.
- اتصال پرداخت و نهایی‌سازی سفارش جزو این مرحله نیست.
- قبل از ورود موجودی واقعی، فایل/منبع انبار باید تطبیق و تأیید شود.

راهنمای endpointها و نمونه JSON در `backend/INVENTORY_API_FA.md` قرار دارد.

در صورت خطا، عملیات را ادامه ندهید و خروجی خطا به‌همراه `docker compose logs --tail=100 api` را ارسال کنید.
