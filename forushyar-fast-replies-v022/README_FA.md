# فورشیار: پاسخ‌های کوتاه کنترل‌شده — نسخه آزمایشی 0.2.2

این بسته فقط برای تست داخلی 300 و کانتینر آزمایشی `forushyar-voice-pilot` است.

- تماس‌های فعال نباید وجود داشته باشند.
- نسخه v0.2.1 اصلاح صدا را دست نمی‌زند.
- SIP، Dialplan، پنل UCM و پنج سرویس اصلی را تغییر نمی‌دهد.
- مدل پیش‌فرض FastAGI از Qwen 3.5 4B به `qwen3:1.7b` تغییر می‌کند.
- پاسخ‌های قطعی مربوط به فهرست محصولات، قیمت، موجودی و تفاوت 9/13 ستون بدون مدل زبانی و سریع بازگردانده می‌شوند.
- بقیه پرسش‌ها به مدل کوچک محلی فرستاده می‌شوند، با Thinking خاموش و حداکثر 90 توکن.
- این نسخه اتصال CRM، قیمت زنده و انتقال تماس ندارد و نباید برای اعلام اطلاعات تأییدنشده به مشتری استفاده شود.

## نصب

فایل zip را در `~/forushyar-AI` روی Debian قرار بده و این دستورات را اجرا کن:

```bash
cd ~/forushyar-AI
unzip forushyar-fast-replies-v022.zip
python3 forushyar-fast-replies-v022/apply.py
```

اگر اسکریپت `STOP` اعلام کرد، تغییری انجام نده؛ خروجی را ارسال کن.

## تست تلفنی

با داخلی 300 تماس بگیر. دو سؤال «چه محصولاتی دارین؟» و «قیمت رابیتس سیزده ستون چنده؟» را آزمایش کن. برای پرسش‌های شناخته‌شده همچنان زمان Whisper (~10 ثانیه) و Piper (~2 ثانیه) وجود دارد. جواب‌های عمومی ممکن است توسط مدل کوچک از نظر لحن ضعیف باشند.

## بازگردانی

```bash
python3 ~/forushyar-AI/forushyar-fast-replies-v022/rollback.py
```

فقط فایل کد آزمایشی از پشتیبان همین مرحله برگردانده و کانتینر `forushyar-voice-pilot` ری‌استارت می‌شود. بسته v0.2.1 و بقیه سرویس‌ها حفظ می‌شوند.
