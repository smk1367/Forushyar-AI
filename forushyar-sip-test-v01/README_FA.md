# فروش‌یار — تست اتصال SIP داخلی 300 (نسخه آزمایشی 0.1)

این بسته یک سرویس Asterisk مستقل به نام `forushyar-sip-test` ایجاد می‌کند و **هیچ تغییری در فایل‌های پروژه Forushyar-AI، دیتابیس، API، UCM یا تنظیمات Ring Group نمی‌دهد**. پس از ثبت موفق داخلی 300، تماس‌های هدایت‌شده به آن فقط پیام خوشامدگویی را پخش می‌کنند و قطع می‌شوند. این **هنوز مکالمه زنده هوشمند دوطرفه نیست**.

## پیش‌شرط

- مسیر `~/forushyar-voice-test.wav` وجود داشته باشد (فایل خروجی صدای Piper که قبلاً ساخته‌اید).
- داخلی 300 در UCM فعال و قابل ثبت از طریق SIP UDP باشد و رمز SIP جداگانه‌اش را داشته باشید.
- IP دستگاه UCM و پورت SIP آن را بدانید (پورت معمول 5060).
- IP محلی سرور که از UCM قابل دسترس است را هنگام اجرا بررسی کنید؛ سرور دو IP در شبکه‌های `192.168.88.x` و `192.168.2.x` دارد.
- TCP 10000 سامانه موجود دست نمی‌خورد. سرویس جدید UDP 5062 و UDP 18000-18050 استفاده می‌کند.
- تصویر Docker مورد استفاده از شخص ثالث `andrius/asterisk:22.11.0_debian-trixie` است. پیش از استفاده در تولید، زنجیره تأمین و سیاست امنیتی را بررسی کنید.

## راه‌اندازی

```bash
python3 configure.py
bash start.sh
```

اولین فرمان با پرسش‌های تعاملی IP و رمز SIP را دریافت و تنظیمات را فقط در `~/.config/forushyar-sip-test` ذخیره می‌کند. رمز را به هیچ‌کس نفرستید. این فایل‌ها را در Git ثبت نکنید.

مشاهده وضعیت رجیستری:

```bash
docker exec forushyar-sip-test asterisk -rx 'pjsip show registrations'
docker exec forushyar-sip-test asterisk -rx 'pjsip show endpoints'
docker logs --tail 70 forushyar-sip-test
```

باید رجیستر داخلی وضعیت Registered نشان بدهد. حالا از شماره شرکت وارد IVR شوید و گزینه 3 را انتخاب کنید. Asterisk باید جواب دهد، پیام فارسی را پخش کند و تماس را قطع کند. این تست تنها پس از رجیستر شدن معتبر است.

## عیب‌یابی

- `Rejected` یا `Forbidden`: اعتبارنامه داخلی، IP allowlist داخلی، SRTP و تنظیمات SIP را بررسی کنید.
- `No response`: مسیر شبکه، IP/port دستگاه، فایروال و UDP را بررسی کنید.
- رجیستری موفق اما تماس نمی‌رسد: تنظیمات Ring Group 6400 و عضویت داخلی 300، وضعیت حضور داخلی و SIP invite را بررسی کنید.
- اتصال بدون صدا: تماس RTP را بررسی کنید؛ UDP 18000-18050 باید از IP UCM به IP سرور قابل دسترسی باشد، کدک PCMA/PCMU فعال باشد.
- اگر داخلی فقط WebRTC/SRTP اجباری است، رجیستری UDP خام ممکن است موفق نشود؛ تنظیمات داخلی در UCM باید با SIP Client سازگار شود.
- روی فایل‌های `pjsip.conf`، `extensions.conf` و `rtp.conf` در مسیر خصوصی config تنظیمات را ببینید؛ **رمز SIP در فایل pjsip.conf وجود دارد، آن را در گفتگو paste نکنید**.

توقف و حذف فقط سرویس آزمایشی:

```bash
bash stop.sh
```

تنظیمات محلی باقی می‌ماند تا بتوانید تست را تکرار کنید. پس از پایان آزمایش می‌توانید آنها را جداگانه با احتیاط پاک کنید.
